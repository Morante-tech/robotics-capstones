# Spider-Bot

Faithful replica of the Spider-Bot from Avengers Campus: 8 legs moved by a single motor, LED eyes, and it walks as soon
as it is switched on (no remote control).

**Hardware plan:** Arduino Nano (ATmega328P) inside the robot, powered by 4×AA NiMH batteries, hand-soldered perfboard.
An Arduino UNO R4 WiFi (from the Starter Kit R4) is used for learning.
