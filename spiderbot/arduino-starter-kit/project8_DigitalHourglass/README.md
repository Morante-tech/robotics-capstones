# Project 8: Digital Hourglass

Six LEDs light up one by one, one per second, using `millis()`; flipping the tilt switch turns them off and restarts
the count.

## Circuit

![Circuit on the breadboard](circuit.jpg)

| Component | Pin |
|---|---|
| LEDs 1–6 | D2–D7 |
| Tilt switch | D8 |
