# Project 2: Spaceship Interface

A push button switches between "idle" (green LED on) and "alarm" (red and yellow LEDs blinking alternately).

## Circuit

| Component | Pin |
|---|---|
| Push button (with pull-down resistor) | D2 |
| Yellow LED | D3 |
| Green LED | D4 |
| Red LED | D5 |
